# olang brand

The visual identity for olang, used by the README and the website. Every
asset is hand-authored SVG generated by one script from one set of design
tokens — no fonts, no external tools, and no rasterizer dependency (the
PNGs are supersampled and encoded in the same script with stdlib `zlib`).
Everything therefore renders identically everywhere and can be
regenerated from scratch:

```bash
cd branding && python3 generate.py
```

## The mark

**The through-line o.** A bold ring — the letter olang is named for —
with the pipeline running straight through it and out both sides.

It states the language's thesis in one glyph: the flow goes in and comes
out, and nothing is concealed inside. The overhang is the point; a bar
that stopped at the ring would read as a prohibition sign, and a bar that
stopped inside it would read as a minus.

It is deliberately **not** a chevron inside a circle. That shape is a
play button — every media player on earth already owns it, and a language
whose whole argument is *this one is different* cannot open with the most
generic icon in software.

The mark is the word's own first letter, so the logo lockup sets it
against `lang` rather than beside a separate wordmark. Standalone, it
holds down to 14 px.

## Palette

| Token | Hex | Use |
|---|---|---|
| Teal | `#2DD4BF` | primary, on dark |
| Deep teal | `#0D9488` | primary, on light (4.5:1 against paper) |
| Amber | `#FBBF24` | accent, on dark |
| Deep amber | `#D97706` | accent, on light |
| Ink | `#0B1220` | dark surfaces, light-bg text |
| Paper | `#E8EFF5` | dark-bg text |
| Slate | `#7C93A8` | secondary text |

Each scheme has its own pair because a hue tuned to glow on ink turns to
pastel on white. Never use the dark pair on a light background.

## The wordmark

Monoline letterforms drawn to the mark's own stroke-to-body ratio. Round
terminals appear only where a stroke genuinely ends, and the round
letters (`o`, `a`, `g`) overshoot the x-height band by 3 units — the
standard optical correction that stops them reading short beside the
flat-shouldered `n`.

## Clear space and minimum size

Keep clear space equal to the ring's stroke weight on every side. Below
about 14 px, use the mark alone; the lockup's letterforms close up.

## What not to do

- Do not recolour the mark outside the palette, or fill the ring.
- Do not trim the through-line to the ring's edge — the overhang is the
  identity.
- Do not set the wordmark in a substitute typeface; the letterforms are
  geometry, not a font, and the whole point is that they need no font to
  render.
- Do not place the dark assets on a light background, or the reverse.
