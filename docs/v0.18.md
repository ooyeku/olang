## Feature 1: Global OTC Management System
**Status**: ✅ COMPLETED  
**Priority**: Critical

**Description**: Establish a standardized global directory structure for managing OTC installation, configuration, and global packages on the user's machine.

**Home Directory Structure**:
```
~/.olang/                        # Main Olang directory
├── otc/                         # OTC-specific files
│   ├── config.toml             # Global OTC configuration
│   ├── bin/                    # OTC binary and tools
│   ├── logs/                   # OTC operation logs
│   └── cache/                  # Temporary cache for operations
├── local/                      # Local package cache
│   ├── packages/               # Downloaded git repositories
│   │   ├── github.com_user_pkg/
│   │   └── gitlab.com_user_pkg/
│   └── metadata/               # Package metadata cache
└── share/                      # Global shared packages
    ├── bin/                    # Global package binaries
    ├── lib/                    # Global package libraries
    └── installed.toml          # Global package registry
```

**Global Configuration (~/.olang/otc/config.toml)**:
```toml
[otc]
version = "0.18.0"
installation_path = "~/.olang/otc"
last_update_check = "2024-01-15T10:30:00Z"

[cache]
directory = "~/.olang/local"
max_size_gb = 10
auto_cleanup = true
cleanup_interval_days = 30

[packages]
global_directory = "~/.olang/share"
prefer_global = false           # Default to project-local packages
allow_global_fallback = true

[network]
timeout_seconds = 30
retries = 3
offline_mode = false

[ui]
color = "auto"                  # auto, always, never
progress = true
verbose = false
```

**Global Package Management**:
```bash
# Install packages globally (available to all projects)
otc install --global math-utils https://github.com/user/math-utils.git
otc install -g web-framework https://github.com/user/web-framework.git

# List global packages
otc list --global
# Global packages:
#   math-utils      v1.2.0    ~/.olang/share/lib/math-utils
#   web-framework   v2.1.0    ~/.olang/share/lib/web-framework

# Remove global packages
otc remove --global math-utils

# Show global package info
otc info --global math-utils
# Package: math-utils
# Version: v1.2.0
# Location: ~/.olang/share/lib/math-utils
# Used by: 3 local projects
```

**Package Resolution Order**:
1. **Project-local packages** - Check project's `packages/` directory first
2. **Project lock file** - Use exact versions from `olang.lock`
3. **Global packages** - Fall back to `~/.olang/share/lib/` if enabled
4. **Download and cache** - Download to `~/.olang/local/packages/` if not found

**OTC Self-Management**:
```bash
# OTC manages itself through the global system
otc update-self                 # Update OTC to latest version
otc config                      # Show current global configuration
otc config set cache.max_size_gb 20
otc config get packages.global_directory

# Cache management
otc cache status                # Show cache size and statistics
otc cache clean                 # Remove unused cached packages
otc cache clear                 # Clear all cached packages
otc cache repair                # Verify and repair cache integrity

# Global system info
otc system-info                 # Show all OTC directories and status
otc doctor                      # Check for common issues and fix them
```

**Automatic Directory Creation**:
- OTC automatically creates `~/.olang/` structure on first run
- Creates directories with proper permissions (user read/write only)
- Initializes configuration with sensible defaults
- Creates global package registry file

**Migration and Cleanup**:
```bash
# Clean migration from older versions
otc migrate                     # Migrate old installations to new structure
otc clean-legacy               # Remove old installation artifacts

# Complete uninstall support
otc uninstall-self             # Remove OTC and all Olang data
# Removes: ~/.olang/, global packages, cached data
```

**Global Package Registry (~/.olang/share/installed.toml)**:
```toml
# Global package installation registry
[packages]

[packages.math-utils]
version = "v1.2.0"
url = "https://github.com/user/math-utils.git"
commit = "abc123def456"
installed_date = "2024-01-15T10:30:00Z"
used_by = ["my-project", "calculator-app", "data-analysis"]

[packages.web-framework]
version = "v2.1.0"
url = "https://github.com/user/web-framework.git"
commit = "def456abc123"
installed_date = "2024-01-14T15:20:00Z"
used_by = ["my-web-app"]
```

**Security and Permissions**:
- All `.olang/` directories are user-only (700 permissions)
- Package downloads verified with git commit hashes
- Global packages isolated from system directories
- No root/administrator privileges required

**Cross-Platform Support**:
- **Linux/macOS**: `~/.olang/`
- **Windows**: `%USERPROFILE%\.olang\`
- **Portable mode**: `./olang-data/` (for USB drives, containers)

## Feature 3: Simple Git Package System
**Status**: IN PROGRESS  
**Priority**: Critical

**Description**: Install packages directly from git repositories with minimal configuration and maximum reliability.

**Core Principle**: No complex registries, no indexes, no servers. Just git repositories with `olang.toml` files.

**Simple Installation**:
```bash
# Install from git URL (any git hosting)
otc install https://github.com/user/math-utils.git
otc install https://gitlab.com/user/web-helpers.git
otc install /local/path/to/package

# Install specific versions using git tags
otc install https://github.com/user/math-utils.git@v1.2.0
otc install https://github.com/user/math-utils.git@main
```

**Package Structure (Simple)**:
```
math-utils/                      # Any git repository
├── olang.toml                   # Required manifest
├── src/
│   └── main.ol                  # Package code
└── README.md                    # Documentation
```

**Minimal Package Manifest**:
```toml
[package]
name = "math-utils"
version = "1.2.0"

# That's it! Everything else is optional.
# No complex features, no dependency hell.
```

**Optional Fields (Keep it Simple)**:
```toml
[package]
name = "math-utils"
version = "1.2.0"
description = "Basic math utilities"        # Optional
authors = ["Alice <alice@example.com>"]     # Optional

[dependencies]
# Only if you need dependencies
other-package = "https://github.com/user/other-package.git"
```

**How Dependencies Work**:
1. **Add to olang.toml** - Just the git URL
2. **Run otc install** - Downloads and caches the package
3. **Use in code** - Import using package name

**Example Usage**:
```bash
# 1. Add dependency to olang.toml
echo '[dependencies]\nmath-utils = "https://github.com/user/math-utils.git"' >> olang.toml

# 2. Install dependencies
otc install

# 3. Use in code
```

```olang
// src/main.ol
use math_utils { add, multiply }

fn main() {
    let result = add(5, 3)
    println("5 + 3 = " + to_string(result))
}
```

**Package Discovery (No Index Required)**:
- **Direct URLs** - Just use the git URL
- **GitHub/GitLab** - Standard git hosting
- **Local Development** - Local filesystem paths
- **Word of Mouth** - Share URLs in documentation, examples

**Local Cache (Simple)**:
```
~/.olang/packages/
├── github.com-user-math-utils/     # Cached repository
│   ├── .git/                       # Full git repo
│   └── olang.toml                  # Package manifest
└── gitlab.com-user-web-helpers/    # Another cached package
    ├── .git/
    └── olang.toml
```

**Version Resolution**:
- **Git tags** - Use semantic versioning tags (v1.2.0)
- **Branches** - Use branch names (main, develop)
- **Commits** - Use specific commit hashes
- **Default** - Use default branch if no version specified

**Error Handling**:
```bash
# Clear error messages
otc install https://github.com/user/nonexistent.git
# Error: Repository not found: https://github.com/user/nonexistent.git
# Check: 1) URL is correct, 2) Repository exists, 3) You have access

otc install https://github.com/user/invalid-package.git  
# Error: Package invalid-package missing olang.toml manifest
# Add olang.toml with [package] section to make this a valid Olang package
```

## Feature 4: Basic Package Management
**Status**: IN PROGRESS  
**Priority**: Critical

**Description**: Essential package management commands that work reliably with the simple git-based system.

**Core Commands (Just What You Need)**:
```bash
# Install packages
otc install                     # Install all dependencies from olang.toml
otc install <git-url>           # Install specific package

# List packages
otc list                        # Show installed packages

# Update packages
otc update                      # Update all packages to latest versions

# Remove packages  
otc remove <package-name>       # Remove package and update olang.toml

# Clean up
otc clean                       # Remove unused cached packages
```

**Installation Process**:
1. **Read olang.toml** - Parse dependencies section
2. **Download packages** - Clone git repositories to cache
3. **Resolve dependencies** - Process each package's dependencies recursively
4. **Create lock file** - Record exact versions for reproducible builds

**Lock File (olang.lock) - Simple Format**:
```toml
# Auto-generated lock file - do not edit manually
[packages]

[packages.math-utils]
url = "https://github.com/user/math-utils.git"
commit = "abc123def456789"
version = "v1.2.0"

[packages.string-helpers]
url = "https://github.com/user/string-helpers.git"
commit = "def456789abc123"
version = "v2.1.0"
```

**Package Cache (Simple Structure)**:
```
~/.olang/cache/
├── packages/
│   ├── github.com_user_math-utils/         # URL converted to safe filename
│   │   └── abc123def456789/                # Commit hash directory
│   │       ├── src/
│   │       └── olang.toml
│   └── github.com_user_string-helpers/
│       └── def456789abc123/
│           ├── src/
│           └── olang.toml
└── .cache-info                            # Cache metadata
```

**Command Examples**:
```bash
# Start new project
otc new my-app
cd my-app

# Add dependencies to olang.toml manually
cat >> olang.toml << EOF
[dependencies]
math-utils = "https://github.com/user/math-utils.git"
string-helpers = "https://github.com/user/string-helpers.git"
EOF

# Install all dependencies
otc install
# Downloads packages, creates olang.lock

# Use in your code
# src/main.ol
use math_utils { add, multiply }
use string_helpers { capitalize }

fn main() {
    let result = add(5, 3)
    let text = capitalize("hello world")
    println(text + ": " + to_string(result))
}

# Update to latest versions
otc update

# List what's installed
otc list
# math-utils (v1.2.0)
# string-helpers (v2.1.0)

# Remove a dependency
otc remove math-utils
# Removes from olang.toml and olang.lock

# Clean unused cache
otc clean
```

**Error Handling**:
```bash
# Missing olang.toml
otc install
# Error: No olang.toml found. Run 'otc new <name>' to create a new project.

# Invalid git URL
otc install https://github.com/user/nonexistent.git
# Error: Failed to clone repository
# Repository may not exist or you may not have access

# Network issues
otc install
# Error: Failed to download package 'math-utils'
# Check your internet connection and try again
# Use 'otc install --offline' to use cached packages only
```

**Offline Mode**:
```bash
# Install from cache only (no network)
otc install --offline

# Show what's available in cache
otc list --cached
```

**Configuration (Optional)**:
```toml
# ~/.olang/config.toml (optional)
[cache]
directory = "~/.olang/cache"
max_size_gb = 5                 # Max cache size in GB

[git]
timeout_seconds = 30
default_branch = "main"
```

**Package Resolution (Simple)**:
- **No version constraints** - Always use latest version (simplest)
- **Git tags** - Use specific git tags when specified
- **Deterministic** - Lock file ensures same versions across machines
- **No conflicts** - Each package gets its own space (no shared dependencies)

## Migration Guide

### From v0.17 to v0.18
**Breaking Changes - Clean Slate Approach**

v0.18 is a foundation reset focused on reliability over backwards compatibility:

1. **New Project Creation** - `otc new` creates different (working) project structure
2. **Simplified Commands** - Many command options removed, streamlined interface
3. **Git-Only Packages** - Package system redesigned around git repositories
4. **Focus on Basics** - Complex features removed to ensure reliability

### Starting Fresh
```bash
# Create new v0.18 project
otc new my-app
cd my-app

# Generated project structure (new):
my-app/
├── olang.toml          # Simple manifest
├── src/main.ol         # Working code 
├── README.md           # Basic docs
└── .gitignore         # Olang-specific

# Run immediately
otc run                 # Works out of the box!
otc test                # Runs the generated test

# Add dependencies (simple)
echo '[dependencies]\nmath-utils = "https://github.com/user/math-utils.git"' >> olang.toml
otc install             # Downloads and caches packages
```

### Publishing Packages
```bash
# 1. Create package
otc new my-library
cd my-library

# 2. Write your code in src/main.ol

# 3. Update olang.toml
cat > olang.toml << EOF
[package]
name = "my-library"
version = "1.0.0"
description = "A useful library"
EOF

# 4. Commit and tag
git init
git add .
git commit -m "Initial commit"
git tag v1.0.0
git push origin main --tags

# 5. Share the git URL!
# Others install with: otc install https://github.com/user/my-library.git
```

## Key Design Principles

- **Reliability First** - Everything must work correctly before adding features
- **Git-Native** - Leverage git for package storage and versioning
- **Minimal Configuration** - Sensible defaults, optional configuration
- **Clear Error Messages** - Help users understand and fix problems
- **Community-Driven** - Simple discovery through GitHub and documentation

## Comparison with Complex Package Managers

| Aspect | Complex Systems | Olang v0.18 |
|--------|----------------|-------------|
| **Setup** | Complex configuration | `otc new` and go |
| **Dependencies** | Version constraints, conflicts | Git URLs, simple |
| **Publishing** | Registry accounts, tokens | Git push + tag |
| **Discovery** | Centralized search | GitHub topics + lists |
| **Offline** | Limited, broken features | Full functionality |
| **Infrastructure** | Expensive servers | Free git hosting |

## Implementation Philosophy

- **Fix the Basics First** - Ensure `otc new` generates working code
- **Simple is Better** - Remove complexity that doesn't add real value  
- **Community Over Infrastructure** - Use existing platforms (GitHub) instead of building new ones
- **Reliability Over Features** - A few features that work perfectly beat many that work poorly
- **Developer Experience** - Make common tasks trivial, complex tasks possible

This release establishes a **solid foundation** that prioritizes reliability and simplicity. Future versions can add sophisticated features on top of this stable base.
