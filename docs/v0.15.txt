# Olang v0.15 Roadmap - Development Tools & Infrastructure

## Overview

Version 0.15 focuses on enhancing **developer productivity** with **2 key infrastructure improvements** that will significantly improve the debugging experience and project configuration management. This targeted approach builds upon v0.14's interpreter improvements while addressing critical polish items identified in development.

## Current Status Assessment

The development infrastructure has solid foundations but needs polishing:
- ✅ Basic module system with import/export functionality
- ✅ OTC (Olang Toolchain) with project scaffolding
- ✅ Comprehensive stdlib with 10+ modules
- ✅ REPL with interactive debugging commands
- ⚠️ **Module resolution lacks debugging visibility**
- ⚠️ **TOML parser is rudimentary and error-prone**

**Enhanced Module Resolution (`src/interpreter.rs`)**:
```rust
impl Interpreter {
    fn resolve_module_path_with_debug(&self, module_path: &str) -> Result<std::path::PathBuf, InterpreterError> {
        let debug_config = &self.module_debug_config;
        let start_time = if debug_config.show_resolution_timing {
            Some(std::time::Instant::now())
        } else {
            None
        };

        if debug_config.enable_resolution_tracing {
            println!("🔍 Resolving module: '{}'", module_path);
        }

        let current_dir = std::env::current_dir()
            .map_err(|e| InterpreterError::RuntimeError { 
                message: format!("Failed to get current directory: {}", e) 
            })?;

        // Enhanced candidate resolution with debugging
        let candidates = vec![
            // Relative to current directory
            current_dir.join(format!("{}.ol", module_path)),
            current_dir.join(format!("{}/mod.ol", module_path)),
            current_dir.join(format!("{}/index.ol", module_path)),
            
            // Relative to src directory
            current_dir.join("src").join(format!("{}.ol", module_path)),
            current_dir.join("src").join(format!("{}/mod.ol", module_path)),
            current_dir.join("src").join(format!("{}/index.ol", module_path)),
            
            // Absolute path if it looks like one
            PathBuf::from(format!("{}.ol", module_path)),
        ];

        if debug_config.log_search_paths {
            println!("  📁 Search paths:");
            for (i, candidate) in candidates.iter().enumerate() {
                let status = if candidate.exists() { "✅" } else { "❌" };
                println!("    {}. {} {}", i + 1, status, candidate.display());
            }
        }

        for candidate in candidates {
            if candidate.exists() && candidate.is_file() {
                if debug_config.enable_resolution_tracing {
                    println!("  ✅ Found: {}", candidate.display());
                    if let Some(start) = start_time {
                        println!("  ⏱️  Resolution time: {:?}", start.elapsed());
                    }
                }
                return Ok(candidate);
            }
        }

        // Enhanced error with debug information
        if debug_config.verbose_error_messages {
            let search_paths: Vec<String> = candidates.iter()
                .map(|p| p.display().to_string())
                .collect();
            
            Err(InterpreterError::RuntimeError { 
                message: format!(
                    "Module '{}' not found.\nSearched paths:\n{}",
                    module_path,
                    search_paths.join("\n  - ")
                )
            })
        } else {
            Err(InterpreterError::RuntimeError { 
                message: format!("Module file not found: {}", module_path) 
            })
        }
    }
}
```

**REPL Debug Commands (`src/repl.rs`)**:
```rust
impl Repl {
    fn handle_module_debug_command(&mut self, args: &[&str]) -> Result<(), ReplError> {
        match args.get(0) {
            Some("trace") => {
                self.interpreter.module_debug_config.enable_resolution_tracing = true;
                println!("✅ Module resolution tracing enabled");
            }
            Some("paths") => {
                if let Some(module) = args.get(1) {
                    // Show what paths would be searched for a module
                    self.show_module_search_paths(module);
                } else {
                    println!("Usage: :module paths <module_name>");
                }
            }
            Some("list") => {
                // List all currently loaded modules
                self.list_loaded_modules();
            }
            _ => {
                println!("Module debug commands:");
                println!("  :module trace     - Enable resolution tracing");
                println!("  :module paths <m> - Show search paths for module");
                println!("  :module list      - List loaded modules");
            }
        }
        Ok(())
    }
}
```

```rust
use serde::{Deserialize, Serialize};
use std::path::Path;

#[derive(Debug, Serialize, Deserialize, Clone)]
pub struct OlangProject {
    pub project: ProjectInfo,
    pub build: BuildConfig,
    pub dependencies: Option<Dependencies>,
    pub scripts: Option<Scripts>,
    pub dev: Option<DevConfig>,
}

#[derive(Debug, Serialize, Deserialize, Clone)]
pub struct ProjectInfo {
    pub name: String,
    pub version: String,
    pub description: Option<String>,
    pub authors: Option<Vec<String>>,
    pub license: Option<String>,
    pub repository: Option<String>,
    pub project_type: ProjectType,
}

#[derive(Debug, Serialize, Deserialize, Clone)]
#[serde(rename_all = "lowercase")]
pub enum ProjectType {
    Application,
    Library,
    Webapp,
    CLI,
}

#[derive(Debug, Serialize, Deserialize, Clone)]
pub struct BuildConfig {
    pub entry_point: Option<String>,
    pub output_dir: Option<String>,
    pub target: Option<String>,
    pub optimization_level: Option<OptimizationLevel>,
    pub features: Option<Vec<String>>,
}

#[derive(Debug, Serialize, Deserialize, Clone)]
pub struct Dependencies {
    pub stdlib: Option<String>,
    pub external: Option<std::collections::HashMap<String, String>>,
}

#[derive(Debug, Serialize, Deserialize, Clone)]
pub struct Scripts {
    pub test: Option<String>,
    pub build: Option<String>,
    pub dev: Option<String>,
    pub lint: Option<String>,
}

#[derive(Debug, Serialize, Deserialize, Clone)]
pub struct DevConfig {
    pub debug_modules: Option<bool>,
    pub enable_repl_debug: Option<bool>,
    pub watch_files: Option<bool>,
}

impl OlangProject {
    pub fn load_from_file<P: AsRef<Path>>(path: P) -> Result<Self> {
        let content = std::fs::read_to_string(path)?;
        let project: OlangProject = toml::from_str(&content)
            .map_err(|e| anyhow::anyhow!("Failed to parse olang.toml: {}", e))?;
        Ok(project)
    }

    pub fn save_to_file<P: AsRef<Path>>(&self, path: P) -> Result<()> {
        let content = toml::to_string_pretty(self)?;
        std::fs::write(path, content)?;
        Ok(())
    }
}
```

**Configuration Validation (`otc/src/config.rs`)**:
```rust
impl OlangProject {
    pub fn validate(&self) -> Result<Vec<ValidationWarning>> {
        let mut warnings = Vec::new();

        // Validate project name
        if !self.project.name.chars().all(|c| c.is_alphanumeric() || c == '_' || c == '-') {
            return Err(anyhow::anyhow!(
                "Project name '{}' contains invalid characters. Use only alphanumeric, underscore, and dash.",
                self.project.name
            ));
        }

        // Validate entry point exists
        if let Some(ref entry_point) = self.build.entry_point {
            if !Path::new(entry_point).exists() {
                warnings.push(ValidationWarning::MissingEntryPoint(entry_point.clone()));
            }
        }

        // Validate version format
        if !is_valid_semver(&self.project.version) {
            warnings.push(ValidationWarning::InvalidVersion(self.project.version.clone()));
        }

        // Check for recommended fields
        if self.project.description.is_none() {
            warnings.push(ValidationWarning::MissingRecommendedField("description".to_string()));
        }

        Ok(warnings)
    }
}

#[derive(Debug)]
pub enum ValidationWarning {
    MissingEntryPoint(String),
    InvalidVersion(String),
    MissingRecommendedField(String),
    UnusedDependency(String),
}
```
